All lettering and symbols are vector paths. No external fonts, embedded
bitmaps, external resources or font installation required. SVG masters
are editable in vector design tools. The original image concept was
redrawn geometrically; this is a reconstruction, not an exact auto-trace.
The lettering is a logotype, not a complete installable typeface.
Colors are sRGB. A printer must prepare CMYK using its output profile.
