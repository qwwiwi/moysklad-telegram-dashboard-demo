# Training-account Seed Implementation Plan

> **For agentic workers:** Use the current-session bounded work packages and verify each result before applying account writes.

**Goal:** Populate the designated MoySklad training account with reproducible, reconciled demo data without touching existing records.

**Architecture:** A pure synthetic-ledger generator feeds an API adapter that resolves references, checks externalCode idempotency and creates missing entities. A separate verifier compares source reports with ledger totals. Dry-run is the default.

**Tech Stack:** Python standard library, unittest, MoySklad JSON API 1.2.

**Spec:** docs/superpowers/specs/2026-11-11-demo-seed-design.md

## Global constraints

No deletion, no overwrites of existing data, no secrets/raw account records in public files. Stable demo codes, fixed dates and random seed. Read and dry-run before apply. Existing organization and primary warehouse remain unchanged. No application deployment or DNS changes.

## Review focus

Duplicate runs; failed/ambiguous network writes; negative stock; transfers mistaken for sales; cash contributions mistaken for revenue; kopeck conversion; incomplete pagination and stale reports.
