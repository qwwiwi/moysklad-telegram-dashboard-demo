# Аудит безопасности ТОВАРНО

Проверено 11 ноября 2026 года. Область — @tovarkonttolbot, app.moyskladdemo.xyz, docs.moyskladdemo.xyz, собственные службы бота/API, приватное хранилище и публичный репозиторий.

## Исправления

- Закрыта самостоятельная регистрация посторонних пользователей. Бот, браузерный API, ключи агента и автоматический импорт проверяют разрешённый Telegram ID. Проверено на рабочем HTTPS: разрешённый ID получает журнал, чужой ID получает 401.
- Ограничено число обрабатываемых HTTP-запросов, время чтения запросов, параллельный разбор таблиц и фоновые импорты.
- Службы ограничены по памяти, числу задач и открытых файлов. API — 512 МБ, бот с распознаванием речи — 1 ГБ, до 64 задач, 4096 файловых дескрипторов.
- На обоих доменах включены запрет встраивания во фрейм, HSTS, no-referrer и nosniff. CSP ограничивает фреймы, object и base URI.
- Копирование API-ключа при отказе буфера обмена сохраняет маску поля.
- Перед новыми загрузками проверяется объём приватного хранилища. Базовые пороги — 1 ГБ на пользователя и 5 ГБ на рабочее пространство. Проверка предшествует записи, одновременные загрузки могут временно превышать порог. Для HTTP-загрузки требуется резерв 1 ГБ свободного диска.
- Идентичность нового заказа и контрагент привязаны к поставщику. Совпадение старых документов требует проверки миграции.

## Подтверждённые защиты

- API слушает только 127.0.0.1:8766. Прямого публичного доступа к этому порту нет.
- Секреты расположены вне web-root, каталог /etc/tovarno имеет режим 0700, файлы ключей — 0600.
- Приватная база и файлы находятся вне публичного каталога, база — 0600, каталог данных — 0700.
- Подписанные initData Telegram проверяются на сервере, сессии браузера используют Secure, HttpOnly и SameSite=Lax. Одноразовые ссылки и ключи хранятся в виде хешей.
- API-ключ пользователя видит только его документы. Просмотр общего журнала определяется отдельным правом.
- Метаданные таблиц выводятся через textContent, запросы к SQLite параметризованы.
- Публичные запросы к .env, .git/config, базе и каталогу загрузок возвращают 404.
- Проверены все 34 коммита истории до исправлений аудита по признакам токенов, приватных ключей и секретных файлов. Совпадений не обнаружено.
- SSH принимает ключи, парольный вход отключён, fail2ban активен.

## Ограничения и оставшиеся вопросы

- Все 44 разрешённых участника имеют доступ к общему журналу для учебного запуска. Это предоставленное владельцем право, его нужно пересмотреть перед использованием реальных данных разных компаний.
- Основная панель содержит опубликованные синтетические данные. Для реального многопользовательского бизнеса требуется отдельное разграничение организаций и доступа к аналитике.
- На общем сервере доступны порты 3389 и 8080 других служб. Их назначение требует отдельного решения владельца, они не закрывались в рамках аудита ТОВАРНО.
- Полный запрет inline-скриптов через CSP пока не введён. Текущая сборка использует встроенные скрипты.
- В тестовом наборе наблюдаются предупреждения ResourceWarning о соединениях SQLite. Проверки завершились успешно, дальнейшее управление соединениями требует отдельной доработки.
- Аудит включает код, конфигурацию и ограниченные внешние проверки. Независимый нагрузочный тест и полноценное тестирование на проникновение не проводились.

## Воспроизведение

Запустите python3 -m unittest discover -s tests из корня репозитория. Проверки включают отзыв ключей, чужие ID, подделку initData, повторное использование ссылок, лимиты HTTP, контрольную сумму файлов, повторный импорт и ошибки таблиц.

Секреты, токены, личные документы и содержание журнала в этот отчёт не включены.
