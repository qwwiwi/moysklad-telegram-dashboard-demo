Работа с ТОВАРНО

ТОВАРНО объединяет панель товаров и финансов с приёмом документов от поставщиков и сотрудников. Откройте бота, выберите роль и передайте документ. История обработки доступна в личном кабинете на телефоне и компьютере.

Открыть бота · Открыть кабинет · Начать работу

С чего начать

  1. Нажмите «Старт» в боте.
  2. Выберите «Загрузить документы», затем роль поставщика или сотрудника.
  3. Отправьте Excel/CSV или получите ссылку для загрузки файла через сайт.
  4. Откройте журнал и проверьте статус, автора и содержание документа.
  5. Если товар требует уточнения, подтвердите соответствие названия артикулу.

Для поставщика и сотрудника

В руководстве описаны приём файлов, голосовые пояснения, вход по ссылке, просмотр истории и исправление ошибок.

Для разработчика и агента

Создайте API-ключ в кабинете и подключите автоматическую загрузку из своей системы. API возвращает номер документа и статус проверки.

Что показывает текущая версия

  • Панель товаров и финансов содержит сохранённые исторические данные МоегоСклада. Блок прямых отгрузок показывает результаты проведённых импортов.
  • Графики Ozon и Wildberries демонстрируют возможный вид аналитики. Подключение кабинетов маркетплейсов предстоит реализовать.
  • Файл до 100 МБ можно сохранить через сайт. Автоматическое проведение поддерживает полностью прочитанные документы до 20 строк данных.
  • Права просмотра журнала определяются Telegram ID. В учебном запуске 44 участникам предоставлен общий журнал.
